Where do I get these?
  1. Address: the web address you open Home Assistant with. From outside your home it must start with https:// (Nabu Casa, DuckDNS or a Cloudflare tunnel).
  2. Token: in Home Assistant tap your name (bottom-left) → Security → Long-lived access tokens → Create token. Copy it here.
  3. Your token is only saved on this phone. It never goes to GitHub.
